# Cafe Menu - Good Coffee. Good Days.

A responsive, pixel-perfect web recreation of the artisanal Cafe Menu, crafted with semantic HTML5, Vanilla CSS, and optimized image & SVG assets.

[![Deploy with Vercel](https://vercel.com/button)](https://money-iota-woad.vercel.app)

**Live Demo**: [https://money-iota-woad.vercel.app](https://money-iota-woad.vercel.app)

---

## Highlights

- **Bit-for-Bit Fidelity**: Faithfully replicates the original layout, organic wavy headers, circular brand mark, typography, and color palette.
- **Pure Web Code**: Zero PDF embeds or iframes. 100% selectable, accessible, and fast-loading web code.
- **High-Resolution Photography**: Optimized assets for the signature brews, coolers, and quick bites.
- **Responsive & Mobile-Ready**: Fluid layout designed for mobile phones, tablets, and desktop displays.
- **Print Friendly**: Built-in CSS print styles for crisp menu prints.

---

## Sections

1. **Header**: Organic olive wave banner with custom botanical logo, headline, and ceramic latte art mug.
2. **Signature Brews**: Caramel Latte, Hazelnut Mocha, Spanish Cold Brew, Oat Milk Cappuccino, and Vanilla Cinnamon Latte.
3. **Coolers**: Iced Matcha Latte, Blueberry Lemonade, Watermelon Cooler, and Peach Iced Tea with `[COLD]` indicators.
4. **Quick Bites**: Grilled Cheese Sandwich, Paneer Tikka Wrap, Peri Peri Fries with vegetarian marks, and Chocolate Brownie.
5. **Footer Ribbon**: Wi-Fi info, Instagram tag, and Takeaway details.

---

## Tech Stack

- **Markup**: Semantic HTML5
- **Styling**: Vanilla CSS (Custom Properties, Flexbox, Grid, Media Queries)
- **Typography**: Google Fonts (`Plus Jakarta Sans` & `Caveat`)
- **Hosting**: [Vercel](https://vercel.com)

---

## Running Locally

Clone the repository and open `index.html` in your browser or run a local static server:

```bash
git clone https://github.com/Sreyash308/money.git
cd money
python3 -m http.server 8000
```
